| # | Improvement | Implementation / regression evidence |
|---|---|---|
| 1 | Responsive layout | UiLayoutPolicy, MainPage.Polish, WrapPanel: compact navigation, stacked header, detail flyout, wrapping collection tools. Native viewport checks. |
| 2 | Always visible Play | GameDetailsPane has independent scrolling content and fixed Play/Launch Options footer. Scroll-position invariant test. |

| 4 | Adaptive Maps | Relative column widths, stacked small-window layout, bounded scroll/preview height; selected-map launching remains available. |

| 10 | Artwork | Uniform aspect ratio for cards/detail media; placeholder on image failure; original files untouched. |
| 11 | Loading/empty/error | Initial statistics use ellipses rather than zero; separate filter-empty explanation and clear-filters action. |
| 12 | Feedback | Routine Close/OK acknowledgements become dismissible non-modal notices, long results retain a Details action. Wizard Next/Finish stays explicit. Errors have expandable technical text. |
| 13 | Themes and focus | Runtime contrast protection, contrasting focus rings, readable finished-entry opacity; native theme checks. User XMLs are never rewritten. |
| 14 | Repeatable QA | Isolated native fixture: five window sizes, four locales, all bundled themes and PNG render outputs at 100/125/150/200%. Existing workflows and data-preserving update checks remain required. |

Run `deployment/test-native-ui.ps1 -PackageDirectory <portable-package>` after building.
The printed fixture path contains `ui-test-report.json` and `visual-qa/*.png` for visual inspection.
The fixture is explicitly marked and never uses a user's live database or archives.

Scaling coverage comprises device-independent layout policy checks and actual XAML
raster exports at the four scales; it does not change the user's Windows display settings.
Hardware-specific monitor/driver behavior is not implied by an offscreen raster test.
The native fixture also moves across each available DisplayArea without changing
Windows settings. `visual-qa/matrix.json` records those displays and their actual
rasterization scales. Oversized restored windows are fitted on monitor changes.

Local acceptance on 2026-11-12: **186 native checks passed**, six bundled themes,
four languages, five viewport sizes, four raster-export scales and three native
display areas (actual 125% and 200% rasterization). Representative PNGs were
visually inspected; the full console suite, reset/version contracts, data-preserving
portable update test and additive schema verification on a private copy of the
existing installation database also passed. No live database migration was run.
