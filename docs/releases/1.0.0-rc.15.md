# Doom Launcher 667 1.0.0-rc.15 — UI polish

- Adaptive navigation, wrapping toolbars and compact detail presentation for small windows; bounded dialog sizing and adaptive map previews.
- Fixed Play/Launch Options footer, launch assignments near the title, grouped entry tools, equal-width personal actions and consistent artwork aspect ratios.
- Readable normal-weight body text, larger metadata, flexible title columns, numeric alignment, full-value tooltips and explicit sorting direction.
- Display effective default source-port/IWAD assignments without changing saved launch definitions.
- Distinguish initial loading, filtered-empty results, an empty library and errors. Routine acknowledgements use non-blocking notifications; technical errors can be expanded. Setup Next/Finish and the metadata-refresh input lock remain intact.
- Theme-aware keyboard focus, stronger finished-entry readability, bounded Home artwork, and native layout/locale/theme/raster regression coverage.

See [the 14-point implementation and validation checklist](../testing/1.0.0-rc.15-ui.md).

Close the launcher before replacing program files. No reset is needed. User databases and Data files are not shipped or replaced. This remains a Release Candidate, not final 1.0.
