# Doom Launcher 667 1.0.0-rc.4

- Protect registered IWAD entries from /idgames mod metadata updates at the database
  write boundary, including entries with an existing incorrect /idgames link.
- Disable mod metadata refresh in IWAD details and the edit dialog. Direct requests
  receive localized guidance; bulk refresh skips IWADs before any network request.
- Keep normal mod metadata/artwork refresh, map counting and launch options intact.
- Add database and native WinUI regression checks for IWAD protection and bulk skips.

## Update

Close the launcher, back up the installation, then extract the Windows x64 ZIP over
the existing program files. Start DoomLauncher667.exe. Personal databases and Data
files are not included in the release. Do not use the reset command for an update.

This release prevents new incorrect assignments; it does not automatically overwrite
existing personal IWAD metadata or guess which older assignments were intentional.
Existing incorrect metadata must be restored from a known-good backup or edited.

This is a Release Candidate, not the final 1.0 release.
