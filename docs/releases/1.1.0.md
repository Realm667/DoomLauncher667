# Doom Launcher 667 1.1.0

This release distinguishes exact IWAD editions and data-file versions in the
Library and game selectors, while retaining existing aliases, IDs and launch choices.
For example, Doom Registered 1.9 and The Ultimate Doom 1.9 remain distinct even
when both files are named doom.wad. Identity information appears in smaller gray
text after the Library title; no separate version column is added.

- Expand the portable catalog to 112 distinct content fingerprints and all 45
  ordered IWAD definitions from UZDoom 5.0.3, including BFG, Xbox, Unity, KEX,
  demos, standalone games and PK3/IPK3 aliases. Recognize renamed known files.
- Keep versions blank when no published fingerprint establishes a revision.
  Generated WadSmoosh data receives no guessed version. Companion music, voices,
  resource packs and ordinary map add-ons are not independent IWADs.
- Import distinct IWAD versions with separate content-qualified ZIP names.
  Preserve original package bytes, reject ambiguous same-name payloads, deduplicate
  identical contents and roll back failed imports without orphan Mod entries.
- Validate full-game dependencies for Deathkings and Strife Veteran Edition and
  prepare the base IWAD separately from the expansion, including renamed bases.
- Check GitHub for newer stable releases in the background. Offer **Jetzt
  aktualisieren**, **Später erinnern** at the next restart and **Version überspringen**.
  Verify SHA-256, back up program files and roll back failed overlays without
  replacing the database or personal Data files.
- Retain all maintenance fixes after 1.0, including **Show in Explorer** and
  refreshing metadata/artwork after replacing a local ZIP with new contents.

## Install or update

Download the Windows x64 ZIP and its SHA-256 file, verify the checksum, then
extract the complete package. Close the existing launcher normally and copy the
program files over the existing portable installation. Start DoomLauncher667.exe.
Do not reset the installation to update. Commercial game data is not included.
No database schema change is introduced by these IWAD/update changes.

## Compatibility and validation scope

Recognition is not a promise that every historical build works with a modern
engine. Alphas, betas and the 2025 Heretic/Hexen KEX remasters can need a different
engine or additional support. UZDoom 5.0.3 changed logfile naming: automatic map
progress is deliberately withheld there and on newer unvalidated UZDoom versions.
Launching and previously stored progress remain available.

Validation includes offline builds, contract/regression tests, native WinUI
workflows, portable overlays/rollback, isolated collection imports and real
UZDoom launches. Six production launch scenarios cover registered/Ultimate Doom,
Doom II, Deathkings, Strife Veteran and Square. The previously supported UZDoom
5.0.0-rc.1 also passes seven real tracking/save/resume scenarios. A clean Windows
installation and playthroughs of every catalog entry remain outside this scope.
