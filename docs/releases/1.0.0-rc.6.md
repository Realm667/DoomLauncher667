# Doom Launcher 667 1.0.0-rc.6

- Personal 1–5 stars, separate from /idgames; no notes feature.
- Ordered Play later queue, with optional removal when finished.
- Random picker filtered by unplayed state, map count, personal stars, IWAD,
  source port and collection.
- Multi-mod launch definitions, finished-state and collection editing with preview
  and an all-or-nothing transaction.
- Metadata old/new previews, field selection, locks, history and guarded undo.
- Manual per-map completion, launch selected / next unfinished map, and spoiler-
  opt-in classic Doom, Hexen and UDMF geometry previews and counts.
- Managed ZIP .zds save browser, import/resume, environment fingerprints,
  pre-session snapshots and verified restore with pre-overwrite backup.
- Zandronum internet/LAN browser, checksum-aware required-file matching,
  confirmed HTTPS or /idgames downloads, direct connections and LAN hosting.
- Multi-PC folder sync using archive SHA-256 identities, three-way per-field
  conflicts, optional settings/saves, retained manifest versions and no shared DB.

## Update and limits

Release Candidate, not final 1.0. Back up and close the launcher before copying
this package over an existing installation. Personal database and Data are not
shipped. Schema revision 2 adds launcher-owned tables without removing library data.

Completion is manual: visited-map statistics do not prove a successful exit.
Map counts are conservative placement counts, not guaranteed runtime totals.
Save resume supports ZIP-based .zds and recognized ZDoom-family executables, not
every engine. Directory-based mod launches retain their previous save behavior.
Changed mods/IWADs/engines may invalidate saves despite confirmation.

The internet browser speaks Zandronum, not a universal protocol. No firewall/UPnP
changes, internet host advertising, password storage or IWAD downloads are performed.
Absent server checksums cannot be verified. Sync requires a shared folder or an
externally configured local cloud folder. It never distributes mods or IWADs;
save deletions are not propagated and duplicate content identities must be resolved.

See [the feature guide](../personal-library-and-multiplayer.md) for details.
