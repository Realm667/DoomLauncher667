# Doom Launcher 667 1.0.0-rc.9

- Align My rating and its stars on one vertically centered row.
- Place Play later and Add to collection side by side below favorites/finished.
- Present multiplayer servers in a sortable nine-column native table, with
  multi-term search, occupancy filters, retained selection and grouped controls.
- Correct the new filter-label bindings and test their actual native rendering.

## Update and limits

Close the launcher and back up the portable installation, then copy the new
program files over the existing installation. No personal database or Data files
are shipped. Do not reset when updating. This is still a Release Candidate.
The [RC6 adapter limits](1.0.0-rc.6.md) remain applicable; automatic map completion
tracking and a central cloud synchronization service are not included.
