# Doom Launcher 667 1.0.0-rc.12

- Move Multiplayer directly above Achievements, with a horizontal divider between them.
- Only show automatic map progress for a compatible assigned source port, including the configured default when using Automatic. Engine API support is checked rather than trusting the displayed port name.
- Keep Maps, map previews and selected-map launching available for other source ports, without progress markers, tracking explanations or the next-unconfirmed-map action.
- Recheck compatibility after changing launch definitions or refreshing the library; recorded completions remain stored when switching ports.
- Add automated service and native UI regression coverage. The RC11 tracking and save-resume fixes remain unchanged.

Close the launcher before updating the program files. No reset is needed; the database and all Data files are preserved. This is a Release Candidate, not final 1.0.
