# Doom Launcher 667 1.0.0-rc.3

## Code and reliability

- Split generator, collection, settings, definition and dialog code into focused
  modules; separate media, definitions and portable packages in the library service.
- Coordinate concurrent refresh requests and retain the latest pending request.
  Preserve unchanged library item objects and update the existing collection.
- Process file imports as a batch, with one final library/statistics refresh.
- Protect the installation with an exclusive file-sharing lease; failed database
  connection setup now disposes its connection. A second cooperating process is
  rejected before opening user data.
- Back up settings and recover from the last valid copy with a visible notice.
  Preserve damaged JSON for diagnosis; unreadable settings are not silently reset.

## UI and UX

- Shared import progress with current file, cancellation, per-file errors and final
  counts; overwrite/skip decisions can apply to remaining conflicts.
- Correct Latest summaries for all import sources; theme-aware New badges with
  localized import-date tooltips and expiry updates only when their state changes.
- Direct source-port/IWAD assignment from mod details with persistent choices and
  localized guidance when launch definitions are missing.
- Retain search, filters, sorting, selected item and scroll position when switching
  sections. Add Ctrl+I, Enter on focused items, Escape and Alt+Left navigation.
- Remove the forced splash delay; retain virtualized list/tile layouts.

## Additional requested features

- Full installation backup with optional mod archives, SQLite snapshot, per-file
  SHA-256 verification and restoration into a separate empty folder.
- Duplicate-mod inspection by file size and SHA-256, grouped paths and potential
  space savings. No automatic file deletion or database merging.

See the [maintenance guide](https://github.com/Realm667/DoomLauncher667/blob/v1.0.0-rc.3/docs/maintenance.md)
for operation, restore limits, network storage and keyboard shortcuts.

## Installation

Download the Windows x64 ZIP and SHA-256 checksum, extract the complete package,
and run DoomLauncher667.exe. Close the launcher and back up the installation
before copying an update over existing program files. Do not use the reset command
to update. Personal databases and Data files are not shipped in release packages.

This remains a Release Candidate. Existing extended device/Windows acceptance
coverage is not exhaustive. Some Obsidian-Content v21 builds replace requested
batch seeds; the launcher records the effective seed reported by the external tool.
