# Doom Launcher 667 1.0.0-rc.1

First Release Candidate for the official 1.0. This is a **prerelease**, not the
final 1.0 approval. No new user-facing features are introduced over 0.9.3.

## Changes

- Consistent `1.0.0-rc.1` title/product version and Windows numeric version `1.0.0.0`.
- Release automation understands beta, RC and stable versions and checks both
  numeric and product versions before publishing. RC packages remain prereleases.
- Updated README and screenshots, installation/update/rollback instructions,
  first-launch migration guide and a privacy-conscious problem-report checklist.
- Portable packages include project licensing, third-party notices, original
  dependency license files and a versioned dependency inventory.

## Download and update

Download `DoomLauncher667-1.0.0-rc.1-win-x64.zip`, compare its SHA-256 with the
attached checksum, and extract it into a writable folder. Start `DoomLauncher667.exe`.
The package is self-contained; .NET need not be installed separately. IWADs,
source ports and optional Obsidian must be supplied by the user.

For an update, close the launcher, back up the complete installation, and copy
the package contents over it. Do **not** run the reset command. Personal databases,
mods, artwork, settings and custom themes are excluded from release defaults.

## Validation scope and known limitations

This RC preparation covers versioning, documentation and distribution. The release
pipeline runs the existing contract, first-setup, reset and portable-update tests.
It does not substitute for the proposed cross-version beta update matrix, a
clean-Windows test, exhaustive end-to-end gameplay or a full DPI/device review.
Those additional acceptance activities have not been performed as part of this RC.

The [0.9.3 stabilization work](https://github.com/Realm667/DoomLauncher667/blob/v1.0.0-rc.1/docs/stabilization-0.9.3.md)
remains the functional baseline. Obsidian-Content v21 may replace the requested
batch seed; effective seed information is recorded, but exact requested-seed
reproducibility is not guaranteed with that build.

Report reproducible problems using the
[reporting checklist](https://github.com/Realm667/DoomLauncher667/blob/v1.0.0-rc.1/docs/reporting-problems.md).
