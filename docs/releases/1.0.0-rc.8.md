# Doom Launcher 667 1.0.0-rc.8

- My rating and its stars now share a vertically centered row.
- Multiplayer uses a native, virtualized table with server name, players, mode,
  map, IWAD, engine version, ping, password status and address.
- Click headers to sort, search across columns, hide full servers or show only
  populated servers. Numeric columns sort numerically; selection survives sorting.
- Discovery settings, required files, technical details and LAN/direct connection
  controls are grouped to keep the browser readable. Existing connection and
  download confirmations remain in place.
- Includes RC7's equal-width Play later / Add to collection action row.

## Update

Close the launcher and back up your portable installation before copying the new
program files over the existing installation. Personal databases and Data are not
shipped in the package. Do not reset when updating. This remains a Release
Candidate; the [RC6 adapter limits](1.0.0-rc.6.md) still apply. Automatic map
completion tracking and a cloud synchronization service are not added by this release.
