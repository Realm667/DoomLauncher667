# Doom Launcher 667 1.0.0-rc.2

- Successful mod imports now open Latest, clear restrictive filters, select the
  newest entry and scroll to the top in both list and tile views. This covers
  file imports, drag-and-drop, Discover downloads, portable packages, generated
  maps and new mods found by Refresh Library.
- Mod artwork displays a New badge for seven days after the stored import date.
  The badge persists across restarts and expires while the launcher is open.
  Metadata refresh does not restart the local import date.

Download the Windows x64 ZIP and SHA-256 checksum. Extract the complete package
and start DoomLauncher667.exe. For updates, close the launcher, back up the
installation and copy the package contents over it. Do not run the reset script.
User databases and Data files are excluded from release defaults.

This remains a Release Candidate. The previously documented extended acceptance
checks remain outstanding. Obsidian-Content v21 can replace the requested seed;
the launcher records the effective seed reported by that external build.
