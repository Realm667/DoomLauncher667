# Doom Launcher 667 1.0.0-rc.10

- Bundle a passive ZScript tracker for compatible GZDoom/UZDoom-based single-player
  launches, including compatible forks detected through their actual engine API.
- Count only automatically validated map completions. There is no manual marking.
  Loading, warp, death, restart, hub travel and ambiguous cases do not count.
  Evidence is session-bound and restricted to the launched archive; an archive
  changed during play is not credited. Results appear after the engine exits.
- Existing manual marks remain stored but are excluded from validated progress.
  The additive schema migration is backed up before modification.
- Remove the cross-PC folder synchronization feature from Library tools and the
  compiled application, including its dialogs, service and unused translations.
- Remove synchronization instructions from the current feature guide and README.
- New installations no longer create synchronization-only tables. Existing inert
  database tables and previously created external sync folders are left untouched;
  no ratings, favorites, collections, maps, saves or archives are deleted.
- Personal library features, managed saves and multiplayer remain available.

## Update

Close the launcher and back up the portable installation before copying the new
program files over the existing installation. No personal database or Data files
are shipped. Do not reset when updating. This remains a Release Candidate.
See the [feature guide](../personal-library-and-multiplayer.md) for exact tracking
limits, supported launch modes and save-game compatibility notes. Engines without
the required API receive no helper and no manual/approximate tracking fallback.
