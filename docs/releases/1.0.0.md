# Doom Launcher 667 1.0

The first stable release of the new portable WinUI 3 Doom library launcher.
Includes collections, personal ratings, Play later, /idgames discovery and import,
artwork and map inspection, native launching, compatible-engine tracking,
multiplayer browsing, backups and optional native Obsidian batch integration.

## Final corrections

- Save source-port names and versions with external paths without trying to
  open a second ContentDialog inside Setup. Portability guidance stays inline;
  the save controls are locked until saving completes.
- Virtualize collection overview cards and bound/recycle accordion and detail
  table rows. Large migrated collections no longer request every mod row at once.
- Honor an explicitly supplied migration destination even without bootstrap
  environment variables, rather than silently falling back to LocalAppData.
- Keep all RC15 responsive UI, accessibility, theme, data-preserving update and
  validated-engine tracking improvements.

## Install or update

Download the Windows x64 ZIP and its SHA-256 file, verify the checksum, extract
the complete package and start `DoomLauncher667.exe`.
Close the launcher and back up the complete portable folder before copying the
new package contents over an existing installation. Do not run reset to update.
Personal databases and files under `Data` are not shipped or replaced.
For rollback, restore the complete old folder into a separate location; do not
point an old executable at a database upgraded by a newer version.

## Validation scope and known limitations

The repeatable acceptance procedure is documented in the
[1.0 acceptance guide](https://github.com/Realm667/DoomLauncher667/blob/v1.0.0/docs/release-acceptance.md).

**A clean Windows 10/11 installation test was not performed: no clean test VM
or separate machine was available.** Existing development-machine and CI tests
are not a substitute. Release approval explicitly retains this test gap.
Windows x64 executables are currently unsigned. Source ports, IWADs and Obsidian
are user-supplied. Some tested Obsidian-Content v21 builds replace requested seeds;
the launcher records the reported effective seed rather than claiming exact
requested-seed reproducibility. Tracking is shown only for verified compatible
engines, not every supported launch target.

Report problems through [GitHub Issues](https://github.com/Realm667/DoomLauncher667/issues),
including launcher/source-port versions and reproduction steps, but no commercial
IWADs or private databases.
