# Doom Launcher 667 1.0.0-rc.5

- Home Featured now randomly selects from all favorite mods, not just the first
  alphabetical favorite or those shown in the limited favorites rail.
- Pick a new favorite whenever Home is entered; avoid repeating the immediately
  previous selection when at least two favorites are available in the session.
- The initial selection is also random on program startup. A single favorite
  remains selected; without favorites, choose an available mod instead.
- Background catalog/statistics rebuilds keep the current featured mod when it is
  still eligible. The favorites rail remains alphabetically sorted.
- Add deterministic selection tests and native WinUI navigation regression checks.

## Update

Close the launcher and back up the installation before extracting the Windows x64
ZIP over existing program files. Start DoomLauncher667.exe. Personal databases and
Data files are not included in the release. Do not use reset to perform an update.

This is a Release Candidate, not the final 1.0 release. Previous RC reliability and
IWAD metadata protections remain included.
