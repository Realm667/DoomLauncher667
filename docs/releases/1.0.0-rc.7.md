## Update

Close the launcher and back up your portable installation before copying the new
package over the existing program files. Personal databases and Data are not shipped
in the package. Do not reset when updating. This remains a Release Candidate, not
final 1.0; the [RC6 features and adapter limits](1.0.0-rc.6.md) remain unchanged.
